# Image assets needed

All diagrams in the lessons are already drawn in SVG inside `content.js`, so they switch colours with the day/night theme and need no files. The images below are photographs and illustrations you need to source and drop into `/assets/images/`. Until a file exists, the lesson shows a dashed placeholder box with the expected filename, so nothing breaks.

Use photos you have the rights to (your own, commissioned, or from a licensed stock library). Save as `.jpg` at around 80% quality, or `.webp` if you update the filename in `content.js`. Keep each file under 250 KB so lessons load on slow mobile data.

## Certificate template (optional)

If you want a designed certificate instead of the plain one Code.gs builds, make a landscape Google Slides file with these placeholders typed into text boxes: `{{FullName}}`, `{{Date}}`, `{{CertificateID}}`, `{{Score}}`. Put its file ID in Script Properties as `CERT_TEMPLATE_ID`.
